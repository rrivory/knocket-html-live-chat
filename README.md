# Knocket Live Chat for HTML

Add free live chat to any HTML website with one script tag.

[View the live demo](https://knocket.trtc.io/) · [Get your installation code](https://console.trtc.io/knocket-installation)

## Install

1. Open the [Knocket installation console](https://console.trtc.io/knocket-installation).
2. Copy the complete one-line installation code.
3. Replace the demo script near the end of `index.html` with your copied line.
4. Publish your site and open it in a browser.

```html
<!-- Your page content -->

<script src="YOUR_KNOCKET_SCRIPT_URL" async></script>
</body>
```

The chat launcher should appear after the SDK loads.

## Run locally

Serve the directory with any static server, for example:

```bash
npx serve .
```
